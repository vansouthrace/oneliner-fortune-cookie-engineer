An entry for the [make.fun bounty "Fortune Cookie Funnies for Engineers"](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a): the funniest one-line fortune cookie message for a software engineer, max 120 characters.

## The entry

> Your future holds a legacy codebase with no comments and one developer who just quit: you.

## How to run

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the single entry line to `/output/entry.txt` and validates the 120-character gate before writing. Requires Node 22.18 or later (it runs TypeScript as-is).
